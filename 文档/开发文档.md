## 1. 项目概述

机动车检验有效期计算与车辆台账管理工具：单文件 exe、绿色免安装，数据只写 exe 同目录的 CSV，不联网上传任何内容。

**两大功能模块**（顶部分段控件切换）：

| 模块 | 功能 | 数据去向 |
|---|---|---|
| ① 临时车辆查询 | 输入车牌/车架号/编号/登记日期/车辆类型/公里数，立即计算检验节点 | 只写「查询历史.csv」留痕，**不进入跟踪库** |
| ② 存量车跟踪管理 | 车辆台账：新增/编辑/删除、Excel 批量导入、逾期提醒、总览、导出 | 读写「车辆跟踪库.csv」 |

**核心计算规则**（依据公安部 2022 年免检新政及 12123 车检计算器口径）：

- **7 类车型**（`车辆类型` 1–7）：3/4/7 类（小微型客车、摩托车、非营运大型轿车）**且无伤亡事故/非法改装被罚** 才享受免检新政 —— 第 2/4/8 年免检领标，第 6/10 年上线检测，第 11 年起每年上线检测。
- **不享受免检**的车型周期：
  - 营运客车（1）：5 年内每年上线，之后每半年。
  - 货车/大中型客车（2）：10 年内每年上线，之后每半年。
  - 面包车（6）、其他机动车（5）、以及 3/4/7 类**有事故**车：6 年内每 2 年、6–15 年每年、15 年后每半年上线。
- **检验有效期止 = 注册登记月的月底**（如登记 `2014-01-10` → 第 6 年节点止于 `2019-01-31`），非登记日当天。
- **办理窗口期**：检验有效期止前 3 个月（约 92 天）。
- **处置管理**：使用满 10 年或累计行驶 30 万公里可处置。
- **20 年节点视图**：自产权登记日起 20 年内全部检验节点（含"已过期 / 窗口期内 / 未到窗口"状态）。

**导入 Excel / CSV 时的车型判断（按 12123 规定的 7 类车型自动归类）**：

- 优先读取表头为 `车辆类型` 的列，按行驶证"车辆类型"文本匹配：`面包`→面包车(6)、`大型轿车`→非营运大型轿车(7)、`摩托`→摩托车(4)、`货车/货/牵引`→货车·大中型客车(2)、`专项作业/其他`→其他(5)，`客车/轿车/载客/小型/微型`→按大小与营运性质归为 营运客车(1)/大中型客车(2)/小微型客车(3)；也接受直接填数字 1–7。
- 若没有"车辆类型"列，则读取表头为 `使用性质` 的列辅助判定：含 `营运/客运/出租/公交`（排除"非营运"）的客车类归 营运客车(1)；`货运/危运` 归 货车(2)。
- 两者都缺时，默认按 **小微型客车(3)** 处理（结果卡片的"规则"列会显示判定出的车型名，可据此核对）。

> 仓库内自带的数据文件（`工程/dist/*.csv`、`示例数据/示例数据.csv`）**全部为虚构演示数据**：车牌 `京A0000x`、VIN 以 `LTEST` 开头。可在界面中一键清空后录入真实数据。

## 3. 技术架构

### 3.1 总体：一个窗口 + 一个 WebView

```
┌─ win.form（无边框 dialog frame）─────────────┐
│  web.view（WebView2，占满窗口）               │
│  ┌──────────────────────────────────────┐   │
│  │  ui/index.html（苹果风 UI）            │   │
│  │  JS: window.aardio.query(...)  ───────┼──► aardio external 表
│  │  JS: window.__recv(json)      ◄───────┼── wb.invoke("__recv", json)
│  └──────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

- **JS → aardio**：`wb.external = { query=...; importFile=...; ... }`；页面上注入的 `window.aardio`
  **就是 external 对象本身**（不是 `aardio.external`！），调用形如 `window.aardio.query(json字符串)`。
- **aardio → JS**：统一走 `wb.invoke("__recv", web.json.stringify(t))`，页面 `window.__recv`
  按 `type` 分发：`init / result / toast / busy / list / overview / detail / remind / history / autoRun`。
- **external 回调不在界面线程**：回调里不要用 `winform.setTimeout`（可能永不触发），统一用同步执行器：

```aardio
var uiDo = function(fn){
    var err;
    try{ fn(); } catch(e){ err = tostring(e); }
    if(err){ busy(false); toast("err","操作失败：" ++ err); }
}
```

### 3.2 界面文件加载

`UI_HTML = $"~/ui/index.html"` 在**编译期**把文件读成字符串常量；`saveUi()` 每次启动都重建
`dist/ui/index.html`（不要做"存在则跳过"的缓存，否则改版后跑的还是旧页面）。

### 3.3 苹果风设计规范（index.html）

- 字体 `-apple-system, "PingFang SC", "Microsoft YaHei"`；背景 `#F5F5F7`；主色 `#0071E3`。
- 白色圆角卡片（radius 18px）+ 柔和阴影；胶囊按钮；iOS 开关；分段控件滑块动画。
- 顶栏 `backdrop-filter` 半透明毛玻璃；状态灯红/黄/蓝/绿；toast 胶囊提示；模态+遮罩。
- 状态徽章：逾期=红、≤92 天=橙、窗口期=蓝、正常=绿。

## 4. 数据文件格式（UTF-8，首行表头，无 BOM 亦可）

**车辆跟踪库.csv**（7 列，exe 同目录）：

```
车牌号,车架号,编号,登记日期,公里数,车辆类型,事故标志
京A00001,LTEST000000000001,T2024001,2014-01-10,,3,0
```

- `车辆类型`：1=营运客车 / 2=货车·大中型客车 / 3=小微型客车 / 4=摩托车 / 5=其他 / 6=面包车 / 7=非营运大型轿车。
- `事故标志`：1=发生过伤亡事故或非法改装被罚（不再享受免检），0=无。
- 兼容旧 6 列格式：第 6 列 `免检新政` 1→归为小微型客车(3)、0→归为面包车(6)。
- 合并去重规则：按 `车牌号+车架号`（或 车牌+登记日期）识别同一台车，导入时更新不重复。

**查询历史.csv**（8 列）：

```
查询时间,车牌号,车架号,编号,登记日期,公里数,车辆类型,事故标志
2026-10-31 12:06,京A00011,LTEST000000000011,T2024011,2021-03-08,,3,0
```

- 只由「临时车辆查询 / 批量导入预览」写入；去重保留最新；上限 200 条（`HISTORY_MAX`）。
- 车牌、车架号、编号全空的查询不写历史（防垃圾记录）。
- 「回看」按列表下标回放计算结果；「清空记录」只清历史不动跟踪库。

## 8. 踩坑经验（重要，改代码前必读）

### aardio 语言

1. **try/catch 是内部函数**：块内 `return` 会截留（调用方拿到 null），块内 `break` 直接编译错误。铁律：try 内只赋值，return 放 try 外。
2. **exe 中前向引用解析为 null**：变量/函数必须先定义后使用；确实需要先用后定义的（如 `exportExcel`），先 `var exportExcel;` 声明再赋值。
3. **字符串字面量里禁止写真实换行**：`string.split(str,'⏎')`（换行写进源码）会导致分隔符失效、解析结果为空表。换行统一用 `string.char(10)`，本项目提供 `splitLines()`。
4. 双引号串不处理 `\r\n` 转义需用单引号；aardio 无三元运算符 `? :`；模式匹配转义符是 `\` 不是 `%`，字面 `:` 要写 `\:`。
5. Excel COM 读值用 `.Value2`（`.Text` 在列窄时显示 `####`）；写日期文本前先设 `NumberFormat="@"`。
6. **取 exe 路径是属性 `io._exepath`（不带括号）**：写成 `io.exepath()` 会报 `Attempt to call exepath Type:null`——函数根本不存在。
7. **托盘菜单必须用 `win.ui.popmenu`**：`win.ui.menu` 构造时执行 `SetMenu()`，菜单会常驻显示在标题栏下方变成窗口菜单栏。

### web.view 双向通信

8. 注入页面的 `window.aardio` **就是 external 对象本身**，写成 `aardio.external.query` 会静默 undefined。
9. external 回调不在界面线程：不要用 `winform.setTimeout`，用同步 `uiDo`。
10. `saveUi()` 每次启动必须重建 index.html，否则改版后跑旧页面。

### 构建与自动化

11. **先启动 IDE 进程再 `import ide`**，否则 `ide.command.joined()` 恒 false；多 IDE 实例并存时 publish 可能发错实例，发布前保证单实例。
12. `ide.publish()` 返回值恒为 null，成败以 dist 中 exe 的修改时间/大小为准。
13. **两个工程同名时最容易发错**：工程 `name` 相同 → IDE 标题分不清，exe 会跑到另一个工程的 `dist/`。自动化发布前先用 `ide.getProjectMainFile()` 校验当前打开的确实是目标工程。
14. **IDE 弹模态框会把外部自动化整体卡死**：发布完成后 IDE 会弹「已生成EXE文件」对话框，此时任何外部命令调用都会挂住（有的客户端会误报成"工具不存在"）。解法：用 `ctypes` 找 `#32770` 窗口，`PostMessage` 点其「确定/关闭」按钮即可恢复。
15. `RAW CALLBACK ERROR` 弹窗的根因：IDE 的 `extensions\trigger\init.aardio` 把外部命令转发为 `ide[method](...)`，method 不存在时对 null 调用即报错——是命令名写错，不是权限问题。
16. GUI 进程由脚本启动时可能被子进程回收机制带走：启动 exe 与后续操作尽量放在**同一个脚本/同一条命令**内完成。

### 窗口与截图

17. 截图进程必须 `SetProcessDpiAwareness(2)`（150% 缩放下否则截到逻辑尺寸）；BMP 位图自底向上，扫描出的 y 要 `h-y` 翻转才是点击坐标。
18. **BitBlt 截的是整窗（含标题栏），`ClientToScreen` 要的是客户区坐标**：两者有固定像素偏移（受 DPI 影响），点小控件前必须先算偏移，别拍脑袋。
19. **最小化到托盘的标准写法**：`wndproc` 拦 `WM_SYSCOMMAND(0x112)` 且 `wParam==0xF020` → `winform.show(false)` + `tray.pop()`；
    恢复用 `winform.show()` + `win.setForeground(hwnd)` + `wb.adjust()`；wndproc 返回非 null 阻止默认处理。
20. **托盘回调消息用库默认 `0xACCF`**：自选 `0x8001`（WM_APP 区）会与 WebView2 宿主内部消息冲突；
    退出前 `tray.delete()` 防幽灵图标。

### 数据

21. aardio `time(数字)` 按 Unix 秒解释，Excel 日期序列号要 `(n-25569)*86400` 换算；13 位毫秒时间戳按秒判年份会错。
22. 跨进程传递代码/文本时路径一律用正斜杠（反斜杠+中文容易丢字符），Excel COM 的 `Workbooks.Open` 也接受 `C:/...` 形式。

### aardio 语法

23. **aardio 不支持三元运算符 `? :`**：`(cond) ? a : b` 会编译报错，改写成 `cond and a or b`（注意 `b` 不能是 `false`/`nil`）。
24. **表构造器 `{ }` 内只能放表达式，不能放语句**：把 `if(...) x = 3;` 写在 `var t = { a=1; b=2 }` 里会报 `<unexpected symbol>` near `if`；校验逻辑必须提到表外算好再塞进字段。

### 发布与数据兼容

25. **发布时报"需要生成的目标EXE正在运行中"（错误码 2712）**：先把正在运行的 exe 进程结束，文件锁释放后才能覆盖写入。
26. **CSV 向后兼容不能只校验"值是否落在目标枚举范围"**：旧列的取值空间可能与新列重叠（本项目旧"免检新政"列的 `1` 恰好是新车型的"营运客车"编号，导致全车队被误判为半年一检）。必须按**表头**判断格式。

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| 启动提示"后台接口未就绪" | WebView2 未注入完成，重启程序；仍不行则安装 WebView2 Runtime |
| 点"导入 Excel 入库"没反应 | 本机需有 Excel 或 WPS；失败详情看 exe 目录 `导入调试日志.txt` |
| 时间不准 | 程序优先用联网北京时间，断网时回退本机时钟 |
| 历史记录想清空 | 查询页「历史查询记录」卡片右上角"清空记录"，只清历史不影响跟踪库 |
| 想开机自启 | 查询页开关"开机自动启动并弹窗提醒"，或托盘右键菜单勾选；本质是写注册表 `HKCU\...\Run` |
| 窗口最小化后不见了 | 程序缩到了系统托盘（右下角），双击托盘图标恢复，右键图标可退出 |
| 托盘图标残留（幽灵图标） | 鼠标划过通知区会自动消失；程序退出时已主动删除图标，正常不会出现 |
| 编译报错找不到 `app.ico` | 确认 `工程/app.ico` 存在且 `default.aproj` 里是 `icon="\app.ico"`（相对工程根目录） |
| 发布时报"目标EXE正在运行中" | 先结束正在运行的 exe 进程再发布（文件被占用无法覆盖） |
| 导入后车型判断不对 | 看结果卡"规则"列显示的车型名；程序先认 `车辆类型` 列文本，无该列时用 `使用性质` 辅助推断，缺列时默认小微型客车(3) |
| 旧版 csv 的"免检新政"列被误读 | 已按表头兼容：`1`→小微型客车(3)、`0`→面包车(6)；建议用新版 7 列格式 |
