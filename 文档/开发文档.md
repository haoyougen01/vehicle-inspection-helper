# 车辆年检助手 · 开发文档

> 版本：V6（WebView2 苹果风界面版）　更新日期：2026-10-31
> 技术栈：aardio + web.view（WebView2）+ HTML/CSS/JS　运行平台：Windows 10/11

---

## 1. 项目概述

面向车队管理员（公交公司）的车辆年检计算与跟踪工具，单文件 exe、绿色免安装。

**两大功能模块**（顶部分段控件切换）：

| 模块 | 功能 | 数据去向 |
|---|---|---|
| ① 临时车辆查询 | 输入车牌/车架号/编号/登记日期/车辆类型/公里数，立即计算检验节点 | 只写「查询历史.csv」留痕，**不进入跟踪库** |
| ② 存量车跟踪管理 | 车辆台账：新增/编辑/删除、Excel 批量导入、逾期提醒、总览、导出 | 读写「车辆跟踪库.csv」 |

**核心计算规则**（依据公安部 2022 年免检新政，可在表单切换）：

- 享受新政（非营运小微型载客汽车/摩托车）：第 2/4/8 年免检领标，第 6/10 年上线检测，第 11 年起每年上线检测（至 60 年）。
- 不享受新政（面包车及其他）：第 2/4/6 年上线检测，第 7 年起每年上线检测。
- **办理窗口期**：检验截止期满前 3 个月（约 92 天）。
- **处置管理**：使用满 10 年或累计行驶 30 万公里可处置。
- **20 年节点视图**：自产权登记日起 20 年内全部检验节点（含"已过期/窗口期内/未到窗口"状态）。

## 3. 技术架构

### 3.1 总体：一个窗口 + 一个 WebView

```
┌─ win.form（无边框 dialog frame）─────────────┐
│  web.view（WebView2，占满窗口）               │
│  ┌──────────────────────────────────────┐   │
│  │  ui/index.html（苹果风 UI）            │   │
│  │  JS: window.aardio.query(...)  ───────┼──► aardio external 表
│  │  JS: window.__recv(json)      ◄───────┼── wb.invoke("__recv", json)
│  └──────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

- **JS → aardio**：`wb.external = { query=...; importFile=...; ... }`；页面上注入的 `window.aardio`
  **就是 external 对象本身**（不是 `aardio.external`！），调用形如 `window.aardio.query(json字符串)`。
- **aardio → JS**：统一走 `wb.invoke("__recv", web.json.stringify(t))`，页面 `window.__recv`
  按 `type` 分发：`init / result / toast / busy / list / overview / detail / remind / history / autoRun`。
- **external 回调不在界面线程**：回调里不要用 `winform.setTimeout`（可能永不触发），统一用同步执行器：

```aardio
var uiDo = function(fn){
    var err;
    try{ fn(); } catch(e){ err = tostring(e); }
    if(err){ busy(false); toast("err","操作失败：" ++ err); }
}
```

### 3.2 界面文件加载

`UI_HTML = $"~/ui/index.html"` 在**编译期**把文件读成字符串常量；`saveUi()` 每次启动都重建
`dist/ui/index.html`（不要做"存在则跳过"的缓存，否则改版后跑的还是旧页面）。

### 3.3 苹果风设计规范（index.html）

- 字体 `-apple-system, "PingFang SC", "Microsoft YaHei"`；背景 `#F5F5F7`；主色 `#0071E3`。
- 白色圆角卡片（radius 18px）+ 柔和阴影；胶囊按钮；iOS 开关；分段控件滑块动画。
- 顶栏 `backdrop-filter` 半透明毛玻璃；状态灯红/黄/蓝/绿；toast 胶囊提示；模态+遮罩。
- 状态徽章：逾期=红、≤92 天=橙、窗口期=蓝、正常=绿。

## 4. 数据文件格式（UTF-8，首行表头，无 BOM 亦可）

**车辆跟踪库.csv**（9 列，exe 同目录）：

```
车牌号,车架号,编号,登记日期,公里数,免检新政
京A00001,LTEST000000000001,T2024001,2014-01-10,,1
```

- `免检新政`：1=享受新政，0=不享受；`公里数` 可留空。
- 合并去重规则：按 `车牌号+车架号`（或 车牌+登记日期）识别同一台车，导入时更新不重复。

**查询历史.csv**（7 列）：

```
查询时间,车牌号,车架号,编号,登记日期,公里数,免检新政
2026-10-31 12:06,京A00011,LTEST000000000011,T2024011,2021-03-08,,1
```

- 只由「临时车辆查询 / 批量导入预览」写入；去重保留最新；上限 200 条（`HISTORY_MAX`）。
- 车牌、车架号、编号全空的查询不写历史（防垃圾记录）。
- 「回看」按列表下标回放计算结果；「清空记录」只清历史不动跟踪库。

## 6. 构建与发布

**方式 A：IDE 手动** —— aardio 打开 `工程/default.aproj`，按 F7 发布到 `工程/dist/`。

**方式 B：编程式发布（推荐，无需人工参与）** —— 前提：aa-bridge 桥（`aacli.exe`，HTTP `127.0.0.1:9123`）在运行；token 实时读取 `%LOCALAPPDATA%\aardio\autos\aa-bridge.table`。

```bash
cd 工具/自动化测试
python run2.py publish2.aardio     # 发布脚本做四件事：
# 1) process.execute 启动 aardio.exe 打开工程（必须先启动 IDE 再 import ide）
# 2) win.delay(8000) 后 import ide → ide.command.joined() 确认入组
# 3) ide.publish()（返回值恒为 null，不能作为成败依据）
# 4) 轮询 dist/车辆年检助手.exe 的修改时间确认构建成功
```

**发布后冒烟测试**：`python hist_probe.py`（启动 → 截图 → 退出，输出窗口句柄与截图路径）。

**已知运行时文件**：`导入调试日志.txt` 仅在 Excel 导入出现异常时由 `dbg()` 写入，属排障日志，可删。

## 8. 踩坑经验（重要，改代码前必读）

### aardio 语言
1. **try/catch 是内部函数**：块内 `return` 会截留（调用方拿到 null），块内 `break` 直接编译错误。铁律：try 内只赋值，return 放 try 外。
2. **exe 中前向引用解析为 null**：变量/函数必须先定义后使用；确实需要先用后定义的（如 `exportExcel`），先 `var exportExcel;` 声明再赋值。
3. **字符串字面量里禁止写真实换行**：`string.split(str,'⏎')`（换行写进源码）会导致分隔符失效、解析结果为空表。换行统一用 `string.char(10)`，本项目提供 `splitLines()`。
4. 双引号串不处理 `\r\n` 转义需用单引号；aardio 无三元运算符 `? :`；模式匹配转义符是 `\` 不是 `%`，字面 `:` 要写 `\:`。
5. Excel COM 读值用 `.Value2`（`.Text` 在列窄时显示 `####`）；写日期文本前先设 `NumberFormat="@"`。

### web.view 双向通信
6. 注入页面的 `window.aardio` **就是 external 对象本身**，写成 `aardio.external.query` 会静默 undefined。
7. external 回调不在界面线程：不要用 `winform.setTimeout`，用同步 `uiDo`。
8. `saveUi()` 每次启动必须重建 index.html，否则改版后跑旧页面。

### 构建与自动化
9. **先启动 IDE 进程再 `import ide`**，否则 `ide.command.joined()` 恒 false；多 IDE 实例并存时 publish 可能发错实例，发布前保证单实例。
10. `ide.publish()` 返回值恒为 null，成败以 dist 中 exe 的修改时间/大小为准。
11. 沙箱会回收 Bash 启动的 GUI 子进程：启动 exe/桥接服务必须与后续操作放在**同一个脚本/同一条命令**内完成；aacli 桥需由用户或系统启动（启动文件夹 `aacli-bridge.bat`）。
12. 截图进程必须 `SetProcessDpiAwareness(2)`（150% 缩放下否则截到逻辑尺寸）；BMP 位图自底向上，扫描出的 y 要 `h-y` 翻转才是点击坐标。

### 数据
13. aardio `time(数字)` 按 Unix 秒解释，Excel 日期序列号要 `(n-25569)*86400` 换算；13 位毫秒时间戳按秒判年份会错。
14. 桥接 HTTP 传输的代码里路径一律用正斜杠（反斜杠+中文会丢字符）；桥接 token 会轮换，每次从 `aa-bridge.table` 实时读取。
15. **取 exe 路径是属性 `io._exepath`（不带括号）**：写成 `io.exepath()` 会报 `Attempt to call exepath Type:null`——函数根本不存在。
16. **托盘菜单必须用 `win.ui.popmenu`**：`win.ui.menu` 构造时执行 `SetMenu()`，菜单会常驻显示在标题栏下方变成窗口菜单栏。
17. **托盘回调消息用库默认 `0xACCF`**：自选 `0x8001`（WM_APP 区）会与 WebView2 宿主内部消息冲突，引发意外行为。

## 9. 常见问题

| 现象 | 处理 |
|---|---|
| 启动提示"后台接口未就绪" | WebView2 未注入完成，重启程序；仍不行则安装 WebView2 Runtime |
| 点"导入 Excel 入库"没反应 | 本机需有 Excel 或 WPS；失败详情看 exe 目录 `导入调试日志.txt` |
| 时间不准 | 程序优先用联网北京时间，断网时回退本机时钟 |
| 历史记录想清空 | 查询页「历史查询记录」卡片右上角"清空记录"，只清历史不影响跟踪库 |
| 想开机自启 | 查询页开关"开机自动启动并弹窗提醒"，或托盘右键菜单勾选；本质是写注册表 `HKCU\...\Run` |
| 窗口最小化后不见了 | 程序缩到了系统托盘（右下角），双击托盘图标恢复，右键图标可退出 |
| 托盘图标残留（幽灵图标） | 鼠标划过通知区会自动消失；程序退出时已主动删除图标，正常不会出现 |
