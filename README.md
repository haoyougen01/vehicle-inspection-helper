# 车辆年检助手（Vehicle Inspection Assistant）

> 一款面向车队 / 个人的 Windows 机动车年检计算与台账工具。单文件绿色 exe，苹果风界面，按公安部 2022 年免检新政与 12123 车检计算器口径，支持 **7 类车型自动判定**、事故车免检资格剔除、逾期提醒、Excel 批量导入与导出。

## 功能特性

**① 临时车辆查询**（不入库，只留痕）

- 输入车牌号 / 车架号(VIN) / 编号 / 产权登记日期 / **车辆类型（7 类）** / **是否发生过伤亡事故或非法改装被罚** / 当前公里数，立即算出下一次年检截止日与剩余天数；
- 自动判定"免检领标"或"上线检测"，并给出办理窗口期（期满前 3 个月）；
- 20 年检验节点全景视图，逐节点标注「已过期 / 窗口期内·可办理 / 未到办理窗口」；
- 处置管理提示（使用满 10 年或行驶满 30 万公里）；
- 查询历史自动留痕（去重、最多 200 条），可回看、可清空，**不会污染车辆台账**。

**② 存量车跟踪管理**（台账）

- 新增 / 编辑 / 删除车辆，默认按紧急程度（距年检到期天数）排序；
- **表头点一下即可排序**：车牌号 / 车架号 / 登记日期 / 车龄 / 下次截止 / 处置，再次点击切换升序、降序，表头带 ▲▼ 指示；
- 六格总览：总数、已逾期、2 个月内、3 个月内、正常、可处置；
- Excel / CSV 批量导入（表头关键字智能识别列，日期格式宽容；**按 12123 规定自动判定 7 类车型** —— 认 `车辆类型` 列文本，无该列时用 `使用性质` 辅助推断）；
- 一键导出跟踪库（CSV，**每台车附带「近 20 年内年检情况」全部检验节点**：检验截止日 / 检验节点 / 办理方式 / 状态）或总览到 Excel（Excel 或 WPS 均可，带样式；可按车导出「**20 年内年检情况**」全节点明细）；
- 启动时自动弹出年检提醒（含开机自启开关，注册表 Run 项，不写快捷方式）；
- 最小化到系统托盘：点最小化或关闭按钮不退出，托盘图标双击恢复，右键菜单可"显示主界面 / 开关开机自启 / 退出程序"。

## 快速开始

1. **开箱即用**：从 [Releases](https://github.com/haoyougen01/vehicle-inspection-helper/releases/latest) 下载 `VehicleInspectionHelper-v1.0.2-win64.zip`，解压到任意文件夹（建议单独建一个，如 `D:\车辆年检助手`）；或按下方「构建」自行编译；
2. 双击 `车辆年检助手.exe` 运行。首次启动会在 exe 同目录自动生成：
   - `车辆跟踪库.csv` —— 车辆台账
   - `查询历史.csv` —— 临时查询留痕
   - `ui/index.html` —— 界面文件（自动重建，勿手改）
3. 想批量导入车辆：管理页 →「导入 Excel 入库」，选择 xlsx/csv；格式参考 `示例数据/示例数据.csv`。

> 数据全部保存在本地 csv 中，绿色免安装、可随目录整体拷贝。删掉 exe 目录的 csv 即等于清空数据。

## 年检规则（内置）

按「**车辆类型**」+「**是否发生过伤亡事故 / 非法改装被罚**」两个字段决定走哪套节点表，车型分 7 类：

| 代码 | 车辆类型 | 免检资格 |
|---|---|---|
| 3 | 9 座（含）以下非营运小微型载客汽车（面包车除外） | 无事故则享受免检新政 |
| 4 | 摩托车 | 无事故则享受免检新政 |
| 7 | 非营运大型轿车 | 无事故则享受免检新政 |
| 1 | 营运载客汽车 | 不享受 |
| 2 | 货车、大中型客车 | 不享受 |
| 6 | 面包车 | 不享受 |
| 5 | 其他机动车（含专项作业车） | 不享受 |

- **免检车型**（3 / 4 / 7 类且无事故）：第 2/4/8 年免检领标，第 6/10 年上线检测，第 11 年起每年上线
- **面包车 / 有事故的免检车型 / 其他机动车**：6 年内每 2 年上线，6–15 年每年上线，15 年后每半年上线
- **营运客车**（1）：5 年内每年上线，之后每半年
- **货车 / 大中型客车**（2）：10 年内每年上线，之后每半年
- 发生过伤亡事故或非法改装被罚 → **不再享受免检**，改按面包车周期上线
- 检验有效期止 = **注册登记月当月底**（不是登记日当天）
- 办理窗口：检验截止日前 3 个月内；可处置：使用满 10 年或行驶满 30 万公里
- 计算基准日 = 产权登记日（月/日对齐，闰年 2/29 自动回退到 2/28）

> 完整规则、各车型逐年节点表见 [Wiki · 年检规则](https://github.com/haoyougen01/vehicle-inspection-helper/wiki/%E5%B9%B4%E6%A3%80%E8%A7%84%E5%88%99)。

## 构建（开发者）

需要 [aardio](https://www.aardio.com/)（Windows）与 WebView2 Runtime（Win10/11 一般自带）。

```text
1. aardio 打开 工程/default.aproj
2. 按 F7 发布 → 产物在 工程/dist/车辆年检助手.exe
```

界面文件通过 `var UI_HTML = $"~/ui/index.html";` 在编译期内嵌，因此**改完 index.html 必须重新发布**；程序启动时还会把界面写到 `dist/ui/index.html` 供 WebView2 加载。

更详细的架构、通信协议、数据格式与 33 条踩坑经验见 [文档/开发文档.md](文档/开发文档.md)。
面向使用者的操作手册（功能逐项说明、年检规则、数据备份、常见问题）见 [Wiki](https://github.com/haoyougen01/vehicle-inspection-helper/wiki)。

## 数据与隐私

- 仓库内所有车辆数据均为**虚构**：车牌形如 `京A00001`、`沪A00010`，VIN 统一以 `LTEST` 开头，编号 `T2024001` 起，姓名/联系方式一概没有。
- 程序不联网上传任何数据（仅可选地取一次网络时间校准本机时钟），台账只写本地 csv。

## 常见问题

| 现象 | 处理 |
|---|---|
| 启动提示"后台接口未就绪" | 缺少 WebView2 Runtime，或界面文件被占用，重启程序 |
| 导入 Excel 没反应 | 本机需装 Excel 或 WPS；失败详情看 exe 同目录 `导入调试日志.txt` |
| 导入后车型判断不对 | 结果卡"规则"列会显示判定出的车型名；程序先认 `车辆类型` 列文本，无该列时用 `使用性质` 推断，都缺时默认小微型客车(3) |
| 结果全是"半年一检" | 多为旧版 csv 的"免检新政"列被误读（已按表头兼容），或车型被判成营运客车(1)/面包车(6)，在编辑里改对车型即可 |
| 时间不准 | 程序优先取网络北京时间，断网时回退本机时钟 |
| 想重置演示数据 | 用 `示例数据/示例数据.csv` 重新导入，或直接替换 `工程/dist/车辆跟踪库.csv` |
